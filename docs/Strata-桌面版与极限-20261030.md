# Strata 桌面版：它是什么、能看到什么、本机极限（RTX 4060 Ti 8G · 2026-10-30 实测）

> 全部结论来自本机实测：`tmp/strata-win.png`（首次启动截图）、`tmp/strata-env.png`（带环境变量启动）、进程树与端口取证。

## 1. 它是桌面端还是网页？——**桌面客户端，UI 用网页技术渲染**

| 证据 | 内容 |
|---|---|
| 可执行文件 | `C:/Project/local_model/strata/app/strata-desktop.exe`（10,155,520 B，MZ/PE，Rust **Tauri** 壳：二进制里 `Tauri` 出现 44 次、`WebView2` 12 次） |
| 子进程（父 PID=11848） | `node.exe`（内置后端）+ `msedgewebview2.exe`（Edge WebView2 渲染器） |
| 主窗口 | 标题 `Strata`，最大化 2062×1118 |
| 本地控制口 | `127.0.0.1:50081` LISTENING（pid=11848）；裸取返回 `401 {"error":"not allowed"}`——要 UI 内部签发的 token，**不是**给人直接开的网页版 |
| 网页资源 | `app/host/dist`（12 MB 前端）+ `app/host/server`（1.4 MB node 后端） |

**结论**：双击就是桌面应用（有窗口、有开始菜单/卸载项），不是"浏览器打开一个网址"；但它**同时**是网页技术栈（WebView2 里的 React 页面）+ 内置 node 服务，所以"桌面端 ≈ 套壳网页 + 本地后端"。另外还有纯终端版（`strata/data/terminal/current/bin/strata.cmd`），那个才是给脚本用的。

## 2. 它能看哪些硬件指标？——**有完整硬件面板**

从前端包里抠出来的标签（`app/host/dist`，原文）：

- `GPU load` / `GPU memory` / **`GPU memory breakdown`** / **`GPU memory for other apps (MiB)`** / `GPU power` / `GPU power draw` / `GPU order` / `{0} GPUs · mean utilization`
- `CPU utilization` / `CPU threads` / `CPU {0} · {1}` / `Cache details appear …`
- 采样字段：`utilizationPct` / `memoryUsedGb` / `temperatureC` / `powerW` / `mem_used` / `gpuLoad`

也就是说：**每张卡的利用率、显存占用（还能按进程拆分，"其他应用占了多少"）、功耗、温度、CPU 利用率与线程数、缓存明细**——用户说的"能直接看全部硬件使用情况"是对的（`hardware` 出现 275 次、`VRAM` 94 次、`nvidia-smi` 11 次）。

## 3. 首次启动会拦住你（这一步我已经绕过）

首次启动截图 `tmp/strata-win.png` 原文：

> Welcome to Strata — Strata found your graphics card: **NVIDIA GeForce RTX 4060 Ti, 8 GB, driver 616.92** — To run models on it, Strata needs one download: **The engine for this card: 620 MB**

它默认只认 `%LOCALAPPDATA%\Strata\components`，所以我们装在仓库里的引擎它看不见，会想再下 620 MB。

**已实测的绕过办法**（截图 `tmp/strata-env.png` 为证）：启动前把 `STRATA_COMPONENTS_DIR` 指到仓库里的组件目录，它就直接跳到引导第二步（Welcome → Your model → Prepare → Make it yours），**不再要求下载引擎**：

```bash
bash C:/Project/local_model/scripts/strata-gui.sh
```

## 4. 代价：GUI 本身很轻，但一加载模型就要独占这张卡

| 时刻 | 显存 | NInfer(8091) |
|---|---|---|
| 启动前 | 7,684 MiB | 200 OK |
| GUI 起来 30 s 后 | 7,684 MiB（不变） | **200 OK，没被挤死** |
| GUI 常驻内存 | 26 MB RSS（node 子进程另算几十 MB） | — |

⇒ **光开界面不占显存**，可以一边让它开着当监控面板、一边跑 NInfer。但一旦在界面里选模型 → 它会拉引擎起服务（默认 8080），那时必须先把 NInfer 停掉，否则两边抢卡（我们踩过：别的进程抢 530 MiB 就能让 llama-server「spill 自杀」）。

## 5. 落点与磁盘

- 全部在 `C:/Project/local_model/strata/`：**112 GB**（`model-data` 110 GB 里含 Qwen3.6-35B-A3B 22.85 GB、Gyro-S 58.49 GB、Qwen3.8-Flash-Next 相关包）。
- C 盘：302 GB 总 / 剩 **36 GB**（89% 已用）。要腾空间，`strata/model-data` 里"下完没跑通"的档可以删（删前问用户）。

## 6. 本机 Strata 的极限（引擎实测，不是我猜的）

`strata/logs/g-G14/g-G15/g-BENCH.log` 原文（Qwen3.6-35B-A3B UD-Q4_K_XL）：

```
context 1024 cells, prompt chunk 128, MTP block loaded, 1.13 GiB of VRAM free
hybrid experts: 0 of 256 per layer in VRAM (0.00 GiB), all 18.75 GiB in pageable host memory
bench 1: pp32 90.2 tok/s, tg8 35.3 tok/s
bench 2: pp32 120.9 tok/s, tg8 42.1 tok/s
```

| 指标 | 本机 Strata（q36 档，最省显存配置） |
|---|---|
| 能起吗 | 能，`READY 1024` |
| 上下文 | **512 或 1,024 cell**（再往上 trunk 4.40 GiB + staging 1.10 GiB 就没地方了） |
| prefill | 120.9 tok/s |
| decode | 42.1 tok/s |
| 专家 | 全部 18.75 GiB 摊在主机内存/磁盘，GPU 里 0% |

⇒ **Strata 在本机是"能跑 1K 上下文、42 tok/s"的玩具**：拿它做长文档/200K 完全没戏（同一张卡上 NInfer 是 40K 池 + 1,001 tok/s prefill + 107 tok/s decode，快一个数量级）。

## 7. 一句话给用户

Strata 桌面版是**真桌面程序**（Tauri+WebView2），硬件面板齐全（GPU 利用率/显存拆分/功耗/温度/CPU），装在我们仓库里 112 GB，用 `scripts/strata-gui.sh` 打开即可、**不用再下 620 MB 引擎**；但它能加载的模型在这张 8 GB 卡上只能开 1,024 上下文——**当监控面板和"另一个选择"可以，当主力不行**。
