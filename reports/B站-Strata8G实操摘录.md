## 一、结论（先看这五条）

1. **真正 8G 显存跑 Strata 的一手实测，全网只捞到 4 条**，全部落在 11-37 t/s：P104-100 8G 11-18 t/s（A）、4060 8G + iq3_s 20-37 t/s 均值 27（B）、笔记本 4060 8G + IQ2_XXS 20-30 多（B）、12G 显存 + 32G 内存读盘稳定 22（B）。
2. **凡标 60-100 t/s 的视频，实机都不是 8G**：20G 显存 + 27G 手动内存（BV1HMHw6wETo）、16G + 64G（BV1LmHq6HEKb / BV1G6nf6kEhP）、48G 内存 + 5070ti（BV18ha16hE94 评论区）。“8G 显存”只是标题里的最低门槛，不是实测机器。
3. **8G 的真正瓶颈是内存不是显存**。多条一手证据互相独立地指向同一句：8G 显存 + 32G 内存是极限线，64G 才是舒适线；“低于 64G 的时候基本上这个事情就不要去尝试了”（BV1uBnn68Ety 原话）。
4. **8G 上的可行量化区间是 IQ2_XXS ～ IQ3_S**，且 IQ3_S 必须配合“系统压缩到 2-3G + 32G 内存 + 关视觉 + KV 降到 Q4 + 上下文降到 100K”。官方自己也推荐 32G 内存 + 8G 以上显存就用 IQ2XS（BV1LmHq6HEKb 评论区怪虫，33 赞）。
5. **“能跑”≠“能用”**：8G 一手用户的原话是“可玩不代表速度快…跑是能跑但速度感人”（BV1EEJ26LEXq）。8G 上跑 IQ2 会被压到“连文字功能都没了，写小说第二轮抄上一段、三四轮不吐字”（BV1LmHq6HEKb 评论区 tife321）。

### BV1HMHw6wETo 国际米兰肠胃（22:16，1.2 万播放）A 级
标题：strata内存32G+8G显存>39G即可不读硬盘跑iq3级85G文件均速66t/s-Gyro-M。**实机：32G 内存 + 20G 显存**。

- 评分（UP 自建 3D 拆解/剧本任务）：DeepSeek V4.1 Flash 线上 93（参考上限）、Gyro-M 70-74、IQ3S 62、Qwen3.8-27B 59、IQ3XXS 47

## 六、工程坑（8G 部署前必须知道的）

1. **端口**：整合包默认门户页 8081、引擎接口 8090（BV1i3nv65E1S）。本机 8081 是生产口，**部署前必须改端口**。
2. **硬盘必须是 SSD**：4090 装机械盘只有 11 token/s，搬 SSD 后 110 token/s（rev @BV18ha16hE94）。Strata 不仅启动读盘，运行时也持续从盘里查信息。
3. **上下文 × 输出的上限会把请求顶成 400**：32K 接 Harness 直接报错，128K 才稳（BV1Q2Hy6NE4k）。
4. **Strata 1.4+ / 0.1.44 与新版 DeepSeek Harness 有兼容 BUG**（BV1pDJ26WEKn）：在 DSH 里无限重复 read、每次吃满 max token，最后 OOM 挂起。解法：装社区预设插件 dsh-qwen38-local-qol，参数用 **128K 上下文 / 32K 输出上限 / 16K 思考预算**（插件默认思考预算只有 8192，是坑），压缩触发点要按“上下文减输出上限”倒推。
5. **低量化 + 长思考 = 死循环**：Q3 以下建议直接关思考，否则思考链被破坏会无限循环，把 max token 全吃在无效思考上（BV1nAtN69Ero 口播；BV1uBnn68Ety 实录“陷入死循环，速度能到 30 多但属于无效的了”）。
6. **MTP 在低显存下可能是负收益**：“我建议你关掉 mtp 再试试，说不定能快一点，显存低了 mtp 负收益的”（清欢牌味精 @BV1nAtN69Ero，23 赞）。
7. **内存分配不要用自动**：手动固定（如 27G），自动分配会触发交换（BV1HMHw6wETo）。
8. **低内存模式 low_ram** 可降系统内存占用；**kvgl** 可把闲置 KV 空间借给专家缓存（仅单卡）——8G 场景两项都值得开。

## 七、8G 该怎么配（把上面拼成一份可执行配方）

- 量化：**IQ2_XS 起步**（官方对 32G 内存 + 8G 以上显存的推荐），想快一点用 IQ2_XXS，想要智商用 IQ3_S 但要接受 20-37 t/s。
- 内存：**32G 是极限线**（要能把系统压到 2-3G，且关掉浏览器等），**64G 才舒服**；“低于 64G 基本上就不要尝试了”是另一位 8G UP 的原话。
- 上下文：**8G 上 32K-100K 是现实区间**；96K 已被多个 8G 用户当作日常值；128K 需要 IQ3_S + 32G 内存 + 关视觉。
- KV：Q4（省内存）或 k8v4（保质量）；显存吃紧就 Q4。
- MTP：设 2；若速度反而下降就关掉。
- 视觉：关掉可省约 1G 显存。
- 端口：改成非 8081/8090。
- 预期：**能用 = 20-30 t/s 级别**（写代码、写文章、接 agent 勉强）；**不能指望 60+**。想要 60+ 请直接上 16G 显存 + 64G 内存。
